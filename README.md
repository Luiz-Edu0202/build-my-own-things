# Build My Own Things

> Learning by rebuilding the tools I use every day.

A personal collection of reimplementations of existing tools and software — built from scratch to better understand how they work under the hood. Inspired by [build-your-own-x](https://github.com/codecrafters-io/build-your-own-x).

---

## Projects

### 📁 Linux File Utils

A from-scratch reimplementation of common Linux file utilities (like `ls`, `cat`, `cp`, `mv`, `rm`) to understand how they interact with the filesystem at a low level.

- **Stack:** `C`
- **Reference:** [YouTube – Building Linux file utils](https://youtu.be/gQRmSlcTq9c?si=AM-OQvA7OUY1TouW)
- **Status:** 🚧 In progress

---

## Why this repo?

- Deepen my understanding of how everyday tools actually work
- Practice systems programming and low-level concepts
- Build a habit of learning by *rebuilding*
